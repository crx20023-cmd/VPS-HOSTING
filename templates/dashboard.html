🤖 Telegram Bot Hosting Guide

🚀 1. Deploy a bot in 60 seconds

DEPLOY NEW APP → Source: 📦 Bot Template → pick PTB / pyrogram / telethon / grammY → ENV tab → add BOT_TOKEN = <token from @BotFather> → START. That's it — long-polling, no webhook needed.

📶 2. Webhook or polling?

Use polling (default in all templates). Webhooks need a public HTTPS URL — this panel runs plain HTTP on your device, so Telegram will reject webhook URLs. If you must use webhooks, put a Cloudflare tunnel / reverse proxy in front and set the webhook URL to your tunnel.

🔁 3. Keep the bot alive

Tick Auto-restart on crash (on by default) — the panel respawns the bot within seconds. Dev mode (top of the app screen) auto-restarts on every file save — perfect while coding. Add a cron job if the bot needs to do something on a schedule.

🛡 4. Bots & sessions

Pyrogram/Telethon sessions are stored in the app folder — they survive restarts and are included in snapshots. Quota stops runaway bots (RAM/CPU). Crash alerts go to your Telegram if you set Alert Bot Token/Chat ID in Admin → Hoster Settings and press TEST NOTIFICATION.

💾 5. Backups

SNAPSHOTS tab = instant app backup + restore. Admin → PANEL BACKUP downloads the whole panel (apps, DB, logs). Logs auto-rotate at 5MB so disk never fills up.
